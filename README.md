# 学生成绩管理系统（C++ · v3）

> 大一练手项目 —— 从零手写的 C++ 控制台程序，第三个版本
>
> **v3 核心改进：用 `std::map` 重构数据存储，查找与删除从 O(n) 优化到 O(log n)**

---

## 功能

| # | 功能 | 说明 |
|---|---|---|
| 1 | **添加学生** | 录入学号、姓名、三门课成绩，自动检查学号是否重复 |
| 2 | **显示所有学生** | 表格形式列出，含总分与平均分（按学号自动排序）|
| 3 | **按学号查找** | 使用 `map::find` 快速定位 |
| 4 | **删除学生** | 删除前**二次确认**，防止误操作 |
| 5 | **修改信息** | 先显示原信息，再输入新信息 |
| 6 | **按总分排名** | 从高到低排序显示 |

## 版本演进

| 版本 | 数据存储 | 主要改进 |
|---|---|---|
| **v1** | `vector<Student>` | 基础功能：添加 / 显示 / 查找 |
| **v2** | `vector<Student>` | 输入错误处理（防死循环）、增删改查、按总分排序 |
| **v3** | ⭐ `map<string, Student>` | **改用键值对存储**、查找删除优化、提取重复代码 |

### v3 具体做了什么

**1. 数据存储从 `vector` 改为 `map`**

```cpp
// v2
vector<Student> students;
students.push_back(m);                        // 添加
for (int i = 0; i < students.size(); ++i)     // 查找要遍历
    if (students[i].id == target) { ... }

// v3
map<string, Student> students;                // 学号 → 学生
students[xuehao] = m;                         // 添加
auto it = students.find(target);              // 查找不用遍历
students.erase(target);                       // 删除一行搞定
```

带来四个好处：

| 好处 | 说明 |
|---|---|
| ① 查找快 | O(n) → **O(log n)**（10 万学生也只需比较约 17 次）|
| ② 删除简单 | 不用算下标，`erase(key)` 一行 |
| ③ **自动排序** | map 内部是红黑树，遍历时**自动按学号升序** |
| ④ **天然查重** | key 唯一，不可能出现重复学号 |

**2. 消除重复代码**

| 提取出的函数 | 原来重复次数 |
|---|---|
| `printOne()` | 3 处（showAll / findStu / modifyStudent）|
| `printHeader()` | 2 处（showAll / modifyStudent）|

**效果**：想改打印格式，只改 1 处即可（改一处，多处生效）。

## 用到的知识点

### STL 容器与算法
- `std::map<string, Student>` —— 键值对容器（底层红黑树）
- `std::vector<double>` —— 存储多门课成绩
- `std::sort` + 自定义比较函数 —— 按总分排序
- **迭代器** —— `find()` 返回迭代器、`it->first`（key）/ `it->second`（value）

### C++ 语言特性
- `struct` + 成员函数（`suanshu()` / `average()`）
- **const 正确性**
  - `const` 成员函数：`double suanshu() const`
  - `const` 引用参数：`const map<...>&` —— 只读 + 不拷贝
- **引用传递** `&` —— 避免整个容器被拷贝
- **范围 for 循环** + `auto`

### 输入处理 ⭐
- `cin.fail()` —— 检测输入失败
- `cin.clear()` —— 清除错误状态（failbit）
- `cin.ignore(10000, '\n')` —— 丢弃缓冲区里的非法输入
- 封装成 `readInt()` / `readDouble()` —— **彻底解决"输入字母导致无限循环"**

### 程序设计
- 每个功能一个函数（职责单一）
- **防御性编程**：空列表检查、学号查重、危险操作二次确认
- **DRY 原则**：提取重复代码

## 编译运行

### Visual Studio 2022（推荐）
1. 双击打开 `Project3.sln`
2. 按 `Ctrl + F5` 运行

### 命令行（g++）
```bash
g++ greenhand3.cpp -o student_manager
./student_manager
```

> ⚠️ **编码说明**：源文件是 **UTF-8 with BOM**。
> MSVC 对"UTF-8 无 BOM"的文件会按系统代码页（GBK）解读，导致**中文乱码**——所以必须带 BOM。

## 已知限制

- ⚠️ **数据不持久化** —— 退出程序后数据全部丢失
- 成绩固定为 3 门
- 学号作为唯一标识，**不可修改**
- "按总分排名"只显示排序结果，**不改变存储顺序**（map 始终按学号排序）
